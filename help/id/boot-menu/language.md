# Bahasa untuk entri ini

Timpa pengaturan bahasa, zona waktu, dan keyboard hanya untuk entri startup ini.
Kolom yang kosong akan menggunakan pengaturan default image.

## Nilai yang diterima

- **Locale** menggunakan nama locale seperti `ru_RU.UTF-8`.
- **Timezone** menggunakan nama IANA seperti `Europe/Moscow`.
- **Keyboard layout** menggunakan kode layout XKB seperti `us` atau `ru`.

## Penyelesaian

Saran berasal dari data locale, zona waktu, dan keyboard yang terpasang di
sistem saat ini. Saran membantu dalam pengejaan tetapi tidak menambahkan data
locale yang hilang ke image yang dibangun.
