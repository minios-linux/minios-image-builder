# Память

Управляйте сжатым zRAM swap, созданным для этой записи.

## Состояние zRAM

**Автоматически** сохраняет значения памяти MiniOS по умолчанию. **Отключено** добавляет `nozram` и отключает параметры сжатия и размера, так как они больше не применяются.

## Сжатие

`zramcomp=` выбирает алгоритм сжатия. Доступные варианты: `lzo`, `lzo-rle`, `lz4`, `lz4hc` и `zstd`. Доступность алгоритмов также зависит от используемого ядра.

## Размер

`zramsize=` задаёт размер zRAM в MiB. Оставьте поле пустым, чтобы MiniOS рассчитала размер автоматически. Большое значение не означает свободную физическую память: сжатые страницы всё равно занимают RAM.
