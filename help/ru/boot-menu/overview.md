# Конструктор загрузочного меню

Создайте видимое стартовое меню из отдельных элементов. Выберите шаблон, затем настройте этот элемент с помощью соответствующих управляющих элементов. Отключённые элементы остаются в проекте, но не отображаются в сгенерированном меню.

## Исходное меню

Перед настройкой конструктор считывает распознанные записи MiniOS, их значения по умолчанию и таймаут, а также поддерживаемые параметры из актуального меню GRUB или нативного SYSLINUX. При редактировании импортированной записи заменяются только параметры, представленные типизированными элементами управления. Остальные аргументы источника сохраняются в шаблоне загрузки. В многоязычном меню каждая локализация сохраняет свои параметры языка, часового пояса и клавиатуры, если вы явно их не переопределите.

## Как формируется запись

Шаблон определяет базовое поведение MiniOS. Затем применяются глобальные экспертные параметры ядра, далее — типизированные опции и дополнительные параметры для этой записи. Для повторяющихся ключ-значение опций MiniOS учитывается последнее значение.

## Шаблоны сессий

Resume использует perchdir=resume. New — perchdir=new. Choose — perchdir=ask.
Fresh не использует селектор постоянства. Копирование в RAM использует toram.

Вы можете создавать несколько записей на основе одного шаблона.

## Типы постоянства

Native сохраняет изменения в директории. Dynfilefs использует расширяемый контейнер,
Raw — образ фиксированного размера, а LUKS — зашифрованный контейнер. SquashFS
возобновляет существующую сжатую сессию. Текущий
initramfs не может создать новую сессию SquashFS.

## Зависимые параметры

Элементы управления становятся недоступны, если они не применимы. Отключение zRAM отключает также параметры сжатия и размера. Для постоянства Native и SquashFS поле размера контейнера не используется.

## Завершение и экспертный ввод

Фильтры модулей автодополняются из модулей, обнаруженных в выбранном источнике. Поля локали, часового пояса и клавиатуры заполняются на основе установленных данных системы. Используйте поле "Дополнительные параметры" только для опций, не имеющих типизированного элемента управления. Неизвестные аргументы, загруженные из старого проекта, сохраняются там же.

## Значения по умолчанию и имена

В настраиваемом меню всегда есть ровно одна запись по умолчанию. Отключение текущей записи по умолчанию автоматически выбирает другую включённую запись. Пустое имя сохраняет заголовок источника или шаблона. Пользовательские имена в ASCII работают в многоязычных меню; в однъязычном меню можно использовать символы, поддерживаемые кодировкой меню этого загрузчика.
