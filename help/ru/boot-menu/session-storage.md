# Сессия и хранилище

Выберите, как эта запись будет находить и сохранять постоянные изменения.

## Выбор сессии

Шаблон записи определяет, будет ли MiniOS возобновлять последнюю сессию, создавать новую или спрашивать при запуске. Тип хранилища не заменяет этот выбор шаблона.

## Тип хранилища

- **Автоматически** сохраняет режим шаблона или сохранённой сессии.
- **Нативный** сохраняет изменения в каталоге на файловой системе Linux.
- **Dynfilefs** использует расширяемый контейнер.
- **Raw** использует образ фиксированного размера.
- **LUKS** использует зашифрованный контейнер.
- **SquashFS** возобновляет существующую сжатую сессию.

Текущий initramfs может возобновлять, но не создавать сессии SquashFS.

## Ёмкость

**Размер контейнера** применяется только к сессиям на основе контейнера, поэтому он отключён для Native и SquashFS. **Свободное место для резерва** резервирует пространство на устройстве постоянства, чтобы сохранённые изменения не заполнили его полностью.

Соответствующие параметры загрузки: `perchmode=`, `perchsize=` и `perchreserve=`.

## Копирование в RAM

`toram=full` копирует всю систему в память. `toram=trim` копирует только отфильтрованный набор модулей. Это может позволить извлечь загрузочное устройство, но требует достаточно RAM для скопированных данных.
