# Язык для этой записи

Переопределить язык, часовой пояс и настройки клавиатуры только для этой записи запуска.
Пустые поля сохраняют значения по умолчанию для образа.

## Допустимые значения

- **Локаль** использует имя локали, например `ru_RU.UTF-8`.
- **Часовой пояс** использует имя IANA, например `Europe/Moscow`.
- **Раскладка клавиатуры** использует код раскладки XKB, такой как `us` или `ru`.

## Завершение

Предложения берутся из данных локалей, часовых поясов и клавиатур, установленных в
текущей системе. Предложение помогает с написанием, но не добавляет отсутствующие
данные локали в собираемый образ.
