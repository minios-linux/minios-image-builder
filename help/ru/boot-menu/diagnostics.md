# Диагностика и расширенные параметры

Настройте журнал загрузки или добавьте параметры, которые не представлены в доступных элементах управления.

## Сообщения загрузки

**Скрыть стандартные сообщения загрузки** добавляет `quiet`. **Включить диагностическое логирование** добавляет
`debug`. Их можно включать независимо друг от друга. Отключите `quiet`, если подробные сообщения загрузки
полезнее, чем чистый экран запуска.

## Дополнительные параметры

Вводите только параметры Linux, MiniOS initramfs или live-config, для которых нет
типового элемента управления. Уже существующие неизвестные параметры сохраняются здесь, а автодополнение
продолжает предлагать распространённые опции.

Параметры, специфичные для записи, добавляются после аргументов шаблона и глобальных аргументов ядра. Для повторяющегося параметра MiniOS `key=value` обычно побеждает последнее значение. Неверные или конфликтующие экспертные параметры могут помешать запуску.
