# Система и модули

Выберите модули и среду запуска для этой записи.

## Фильтры модулей

**Загружаемые модули** ограничивают загрузку совпадающими именами или диапазонами модулей.
**Пропускаемые модули** исключают совпадающие модули. Предложения берутся из модулей,
обнаруженных в выбранном источнике MiniOS.

Эти элементы управления создают `load=FILTER` и `noload=FILTER`. Используйте только такие
формы фильтров, которые поддерживаются initramfs MiniOS.

## Среда запуска

Оставьте образ по умолчанию, запустите графическую среду, используйте текстовую консоль или
войдите в режим восстановления. Текстовый и аварийный режимы предназначены для администрирования
и устранения неполадок, а не для обычного использования рабочего стола.

## Совместимость с графикой

Режим совместимости добавляет параметр ядра Linux `nomodeset`. Используйте его, если обычная
установка режима ядра мешает запуску графической системы. Это может снизить
разрешение экрана и ускорение.

## Автоматическое монтирование дисков

Включайте автоматическое монтирование только если после запуска сессии
необходимо предоставить доступ к другим подключённым файловым системам.
