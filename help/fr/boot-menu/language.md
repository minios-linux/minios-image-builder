# Langue pour cette entrée

Remplacez la langue, le fuseau horaire et les paramètres de clavier uniquement pour cette entrée de démarrage.
Les champs vides conservent les paramètres par défaut de l’image.

## Valeurs acceptées

- **Langue** utilise un nom de locale tel que `ru_RU.UTF-8`.
- **Fuseau horaire** utilise un nom IANA tel que `Europe/Moscow`.
- **Disposition du clavier** utilise un code de disposition XKB tel que `us` ou `ru`.

## Saisie semi-automatique

Les suggestions proviennent des données de langue, de fuseau horaire et de clavier installées sur le système actuel. Une suggestion aide à l’orthographe mais n’ajoute pas de données de langue manquantes à l’image générée.
