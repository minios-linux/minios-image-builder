# Idioma para esta entrada

Anula la configuración de idioma, zona horaria y teclado solo para esta entrada de inicio.
Los campos vacíos mantienen los valores predeterminados de la imagen.

## Valores aceptados

- **Idioma** utiliza un nombre de locale como `ru_RU.UTF-8`.
- **Zona horaria** utiliza un nombre IANA como `Europe/Moscow`.
- **Distribución de teclado** utiliza un código de diseño XKB como `us` o `ru`.

## Completado

Las sugerencias provienen de los datos de idioma, zona horaria y teclado instalados en el sistema actual. Una sugerencia ayuda con la ortografía pero no agrega datos de idioma faltantes a la imagen generada.
