# Language for this entry

Override language, timezone, and keyboard settings for this startup entry only.
Empty fields keep the image defaults.

## Accepted values

- **Locale** uses a locale name such as `ru_RU.UTF-8`.
- **Timezone** uses an IANA name such as `Europe/Moscow`.
- **Keyboard layout** uses an XKB layout code such as `us` or `ru`.

## Completion

Suggestions come from locale, timezone, and keyboard data installed in the
current system. A suggestion helps with spelling but does not add missing
locale data to the built image.
