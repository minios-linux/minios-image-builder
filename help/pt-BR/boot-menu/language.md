# Idioma para esta entrada

Substitua as configurações de idioma, fuso horário e teclado apenas para esta entrada de inicialização.
Campos em branco mantêm os padrões da imagem.

## Valores aceitos

- **Localidade** usa um nome de localidade como `ru_RU.UTF-8`.
- **Fuso horário** usa um nome IANA como `Europe/Moscow`.
- **Layout de teclado** usa um código de layout XKB como `us` ou `ru`.

## Conclusão

As sugestões vêm dos dados de localidade, fuso horário e teclado instalados no
sistema atual. Uma sugestão ajuda com a ortografia, mas não adiciona dados de
localidade ausentes à imagem criada.
